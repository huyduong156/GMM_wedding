# Wedding Visual Style Catalog

Catalog này bổ sung các phong cách visual cho hệ thống template. Style là công cụ art direction, không phải checklist bắt buộc: mỗi theme chọn mức độ phù hợp với concept, nội dung, asset và ngân sách performance.

## Nguyên tắc lựa chọn

- Theme thiên về vật thể, editorial, cinematic hoặc fantasy có thể dùng 2.5D ở mức medium/high.
- Theme botanical, watercolor hoặc truyền thống chỉ dùng depth nhẹ nếu giúp tách lớp, không làm mất chất liệu gốc.
- Theme tối giản, typography-first hoặc ưu tiên tốc độ có thể không dùng 2.5D.
- Không dùng perspective, parallax hay tilt chỉ để “trông hiện đại”; mọi lớp phải có vai trò foreground, subject, information hoặc atmosphere.
- Mobile và reduced motion luôn có composition tĩnh hoàn chỉnh, không phụ thuộc chuyển động để tạo hierarchy.
