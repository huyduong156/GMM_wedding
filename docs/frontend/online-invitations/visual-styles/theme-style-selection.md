# Ma trận lựa chọn style theo theme

| Theme direction | 2.5D | Parallax | Z-axis | Gợi ý |
|---|---:|---:|---:|---|
| Modern luxe / couture | High | Medium | High | paper theatre, floating photo deck, vellum plane |
| Cinematic / fantasy | High | High | High | layered scene, match cut, foreground occlusion |
| Storybook / chibi | Medium-High | Medium | Medium | diorama, cut-paper character layers |
| Botanical / greenhouse | Light-Medium | Light | Light | foliage foreground, dappled light, shallow depth |
| Watercolor / romantic | Light | None-Light | None | paper texture, soft overlap, static depth |
| Traditional Vietnamese | Light | None | Light | layered seal, lacquer/gilded frame, restrained reveal |
| Minimal / typography-first | None-Light | None | None | spacing, type hierarchy, material detail |

## Quy trình chọn

1. Xác định vật liệu và câu chuyện chính của theme.
2. Chọn một depth focal point: opening, hero hoặc gallery.
3. Chọn tối đa hai pattern hỗ trợ; phần còn lại giữ phẳng để tạo nhịp nghỉ.
4. Xây composition tĩnh trước, sau đó mới thêm motion.
5. Kiểm tra mobile/reduced-motion; nếu bản tĩnh mất hierarchy thì composition chưa đạt.

## Áp dụng hiện tại

- `Élan d’Amour`: high ở opening/hero, medium ở gallery, light ở content section.
- `Verdant Promise`: light-medium ở hero/edge atmosphere; không biến botanical art direction thành 3D-first.
- `Mây Hồng Có Đôi`: phù hợp medium-high dạng storybook diorama trong lần nâng cấp riêng.
