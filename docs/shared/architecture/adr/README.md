# Architecture Decision Records

Mẫu ADR:

```markdown
# NNNN - Tên quyết định
Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
```

Đánh số tăng dần từ `0001`, không tái sử dụng số.
