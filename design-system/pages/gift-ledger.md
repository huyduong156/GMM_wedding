# Gift Ledger Override

Inherits `../MASTER.md`. This is an owner-only private record, not a revenue dashboard.

- Show a persistent privacy notice and mask aggregate money by default. Reveal is an explicit button with an accessible state label.
- Primary list exposes guest, gift type/value, receive method/date and reciprocity status. Money uses tabular figures and VND formatting.
- Search and filters work without revealing aggregate values. Avoid charts and celebratory animations around money.
- Desktop uses a compact semantic table; below 720px use cards with 44px actions.
- Add-entry dialog separates money from physical gifts and uses explicit labels.
- Owner-only is a backend authorization rule; UI copy/menu visibility is supporting communication, not security.
