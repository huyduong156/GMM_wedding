# Todolist Override

Inherits `../MASTER.md`. This is a planning workspace, not a project-management cockpit.

- Default to a deadline-oriented list grouped by task status; do not require drag-and-drop to complete core actions.
- Header shows progress and one primary `Thêm công việc` action. Search/filter remain secondary.
- Task rows expose checkbox, title, category, deadline, priority and assignee without hover. Completion is keyboard-accessible.
- A secondary rail contains progress distribution and curated checklist templates. Applying a template is clearly described as adding editable tasks.
- Overdue state always uses icon/text in addition to color. Priority labels use text.
- Desktop uses list + 280px rail; below 980px the rail stacks. Below 680px rows become touch-friendly cards and filters scroll horizontally.
- Add-task dialog uses explicit labels, inline validation and 44px mobile controls. No drag-only interaction.
