# AI wedding couple 003

Sixteen fictional wedding demo images generated with OpenAI ImageGen. This is a Vietnamese-looking fictional couple, unrelated to sets 001 and 002. The four solo reference images are full-body outdoor views; all twelve couple concepts are outdoors. Two new horizontal couple portraits were added on 2026-11-02: `couple-pose-11-stone-arch.webp` and `couple-pose-12-garden-veil.webp`.

Images are generated content and do not depict real people. The contact sheet was cropped into individual WebP files at quality 91; grid gutters were excluded.
